## How I Work

I use a structured, AI-assisted software development workflow.

1. Analyze business requirements and define the application's scope.
2. Plan UX/UI, architecture, data structures, and implementation tasks.
3. Prepare technical specifications and development documentation.
4. Use OpenAI Codex to support implementation and technical analysis.
5. Review changes, investigate issues, validate functionality, and run project checks.
6. Test features and commit verified changes using Git.

I see AI as a development tool, not a replacement for understanding the product, making technical decisions, or taking responsibility for the result.

My approach is to work in small, controlled iterations rather than introduce unnecessary complexity.
